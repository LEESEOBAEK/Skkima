# 검증 원칙

쓰끼마는 화면이 열리는 것뿐 아니라 프로젝트에서 결과 검토까지 이어지는 흐름을 검증 대상으로 삼습니다.

## 검증 영역

- JavaScript와 Rust 단위·통합 테스트
- Windows 설치, 재설치와 제거
- Codex, Claude Code, Antigravity 감지와 프로젝트별 실행
- 프로젝트·작업 세션·Run 관계와 중단 후 복구
- 근거, 산출물과 다음 행동 표시
- 공개 패키지의 절대 경로, 비밀값과 개인 작업 데이터 제외

## 공개 원칙

- 테스트 수는 최종 공개 후보를 다시 검증한 결과만 기록합니다.
- 설치 파일의 SHA-256은 해당 Release에 함께 제공합니다.
- 확인하지 않은 환경과 기능은 지원 범위로 표기하지 않습니다.
- 발견된 제한사항은 완료 기능과 분리해 기록합니다.

구체적인 테스트 결과는 첫 공개 Release가 준비되면 별도 보고서로 추가합니다.
