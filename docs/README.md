## 현재 문서

- [구조와 책임 경계](architecture.md)
- [검증 원칙](verification.md)

## 확장 순서

다음 문서는 해당 기능과 공개 자료가 준비되었을 때 추가합니다.

1. `product-tour.md`: 실제 사용자 흐름과 화면
2. `skills-and-plugins.md`: 스킬 수집, 등록, 설치와 격리
3. `troubleshooting.md`: 설치 및 실행 문제 해결
4. `release-guide.md`: 설치 파일, 체크섬과 버전 정책

문서는 기능 구현보다 앞서 완성된 것처럼 작성하지 않습니다. 현재 동작, 검증 결과와 제한사항을 함께 기록합니다.
