# 문제 해결

## CLI가 바로 종료되는 경우

1. 프로젝트 폴더가 실제로 열려 있는지 확인한다.
2. 해당 프로젝트에 Workflow 계약 파일과 준비된 Run이 있는지 확인한다.
3. 선택한 Codex·Claude Code·Antigravity가 PowerShell에서 직접 실행되는지 확인한다.
4. 앱의 실행 기록에서 종료 코드와 로그 경로를 확인한다.

실행 기록이 없는 상태에서 성공으로 판단하지 않으며, 실패 원인이 확인되지 않으면 새 Run을 임의로 만들지 않는다.

## 한국어 프롬프트가 물음표로 보이는 경우

Windows PowerShell에서 긴 다국어 프롬프트를 표준입력으로 전달하면 CLI 구현이나 콘솔 경로에 따라 표시가 깨질 수 있다. 쓰끼마 0.1.5에서는 Codex 실행 시 프롬프트를 하나의 안전하게 인용된 Windows 인수로 전달하는 경로를 사용한다.

설치본을 교체한 뒤에도 문제가 재현되면 다음 정보를 함께 확인한다.

- 쓰끼마 버전
- 선택한 CLI와 버전
- 프로젝트 경로
- 실행 기록의 종료 코드
- 원본 prompt 파일이 깨졌는지 여부

API 키, 로그인 정보와 전체 실행 로그는 공개 이슈나 포트폴리오 저장소에 올리지 않는다.

## 실행이 중단된 경우

중단 기록은 삭제하지 않는다. Workflow가 아직 실행 가능한지 확인한 뒤 재시작하고, 이미 완료된 Workflow라면 기존 산출물과 검증 결과를 보존한 채 새 작업으로 분리한다.

## 브라우저 근거가 비어 있는 경우

브라우저 근거는 사이트의 로그인 상태와 페이지 구조에 의존한다. 읽을 수 있는 내용이 없으면 페이지 진단 결과와 제한사항을 확인하고, 읽기 범위를 벗어난 입력·비밀번호·자동 제출은 수행하지 않는다.
