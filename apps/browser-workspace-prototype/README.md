# 쓰끼마

Schema Workflow의 Windows 데스크톱 앱입니다. Tauri로 만든 독립 실행 창이며 기존
Workflow 프로젝트의 계약과 Run 기록을 확인하고, 준비된 Run을 선택한 AI CLI로 넘길 수
있습니다.

## 실행

```powershell
cd .\apps\browser-workspace-prototype
npm ci
npm run dev
```

상태 규칙 테스트는 다음 명령으로 실행합니다.

```powershell
npm test
```

배포용 실행 파일을 만들려면 다음 명령을 사용합니다.

```powershell
npm run build
```

빌드가 통과하면 현재 Windows 사용자용 NSIS 설치 프로그램이
`src-tauri\target\release\bundle\nsis`에 생성됩니다. 엔진 릴리스와 데스크톱 앱은
별도 버전으로 관리하며, 이 공개 스냅샷의 데스크톱 앱 버전은 `0.1.8`입니다.

## 제거와 데이터 보존

일반 제거는 공용 플러그인·스킬 라이브러리와 프로젝트 내부에 설치된 스킬을
유지합니다. 제거 프로그램에서 앱 데이터 삭제를 선택하면
`%LOCALAPPDATA%\Skkima`의 공용 플러그인·스킬 라이브러리도 함께 삭제합니다.
프로젝트의 `.agents\skills`와 `.claude\skills`는 프로젝트 파일 보호를 위해
항상 유지합니다. 업데이트 설치는 이 선택과 관계없이 모든 라이브러리를 보존합니다.

## 로컬 환경 진단

왼쪽 패널 하단의 `로컬 앱 준비됨`을 누르면 다음 정보를 읽기 전용으로 확인합니다.

- Windows 버전, 아키텍처, CPU, 메모리, GPU
- Python, WSL, Docker, Git, Node.js
- Codex, Claude Code, Antigravity, Cursor, VS Code

진단은 설치나 설정을 변경하지 않으며 계정, API 키, 사용자 경로를 수집하지 않습니다.

## 현재 범위

- 기본 창 크기 `960x640`, 최소 창 크기 `440x560`
- 커스텀 Windows 제목 표시줄
- 최소화, 최대화, 복원, 닫기
- 뒤로 가기와 앞으로 가기
- 파일, 편집, 보기, 도움말 메뉴
- 상단 버튼으로 고정하거나 왼쪽 가장자리에서 임시로 여는 프로젝트 패널
- 실제 Windows 프로젝트 폴더 선택
- 프로젝트 폴더와 작업 세션 분리
- `.schema-workflow.json` 계약과 `workflow_manifest.json` Run 기록 읽기
- 새 프로젝트 준비와 독립·이어가기·분기 작업의 Run 계약 생성
- Codex, Claude Code, Antigravity 중 설치된 CLI 선택
- 별도 PowerShell 창에서 사용자 확인형 CLI 실행
- 실행 상태와 로그 경로의 프로젝트 내부 기록
- 앱 재시작 후 실행 상태 복원과 완료된 Run 자동 새로고침
- 상태, 검증, 산출물 수, 다음 행동과 최종 산출물의 운영 요약
- 전체 Run ID, Operation ID와 산출물 경로의 상세 보기
- 고정 프로젝트, 최근 프로젝트, 프로젝트·세션 검색
- 패널 고정 상태, 프로젝트 목록, 작업 세션의 로컬 저장
- 프로젝트 목록 제거와 실제 폴더 삭제의 안전한 분리
- 새 작업, 현재 작업명·개수, 작업 메뉴를 제공하는 전용 작업 바
- 현재 작업 정보 확인과 이름 변경
- 작업 화면과 작업 개요를 나란히 보는 분할 보기
- 중앙 작업 영역에 집중하는 기본 셸
- 좁은 창에서 접히는 상단 메뉴

CLI 실행은 준비된 Run을 재사용하며 새 Run을 임의로 만들지 않습니다. 자동 승인이나 권한
우회 옵션은 사용하지 않고, 별도 PowerShell 창에서 플랫폼의 권한 요청을 사용자가 직접
확인합니다. 앱은 원본 산출물을 편집하지 않으며 검토 대기 집계와 산출물 편집은 후속
단계에서 추가합니다.
